Two instruments, both runnable right now with zero keys and zero network:

```bash
node mesh/crosswalk.mjs   # quilt-canary × loom witness: ASCII agreement proven
                          # byte-exact (8/8), unicode domain boundary pinned (4/4),
                          # bred elites judged against the fleet standard
node mesh/bazaar.mjs      # the Poly-GAN: two doctrinal minds breed, trade,
                          # weave — bloodline coverage 2→3 per mind, solo cap 2
```

Read [ECOSYSTEM.md](ECOSYSTEM.md) for the mesh map of the hundred-repo fleet,
and [POLY-GAN.md](POLY-GAN.md) for the trade protocol and the v1 lesson
(seed-diversity is fake-diversity; doctrine-diversity is real).

The vendored `engine/` is SuperInstance/quilt (Apache-2.0) — see NOTICE.
`mesh/` sources are extracted from loom-core; `contracts/` from quilt-loom's
foundry targets. The crosswalk vendors quilt-canary's semantics with
attribution — that is the mesh working: nothing here re-implements what the
fleet already shipped, everything cites and receipts it.
